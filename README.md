# JazzCash Mini-Application

A beginner-level console application that simulates basic mobile wallet operations inspired by JazzCash.

## Overview

This project was created as part of my Computer Science learning journey to practice building a real-world style application.

The application provides an interactive menu where a user can authenticate using a PIN and perform basic wallet operations.

## Features

- PIN-based login
- Check account balance
- Send money simulation
- Mobile load simulation
- Balance deduction after successful transactions
- Mobile number validation
- Transaction amount validation
- Insufficient balance handling
- Interactive menu

## Application Flow

```text
PIN Authentication
        ↓
    Main Menu
        ↓
 ┌──────┼─────────┐
 ↓      ↓         ↓
Balance Send    Mobile
Check   Money    Load
        ↓         ↓
   Validation & Balance Update
```
